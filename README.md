# SVG Icon Pack — Organized by Category

5,773 generic UI icons, split by style and category for easy browsing and reuse.

## Contents

- `icon-pack/outline/<category>/*.svg` — 4,754 line-style icons across 40 categories
- `icon-pack/outline/<category>/*.svg` (filled variants) — see `icon-pack/filled/<category>/*.svg`, 1,019 icons across the categories that have a filled counterpart
- `icon-pack/category-manifest.json` — per-category counts for both styles

## Categories

Animals, Arrows, Badges, Buildings, Charts, Communication, Computers, Currencies,
Database, Design, Development, Devices, Document, E-commerce, Electrical,
Extensions, Food, Games, Gender, Gestures, Health, Laundry, Letters, Logic,
Map, Math, Media, Mood, Nature, Numbers, Photography, Shapes, Sport, Symbols,
System, Text, Vehicles, Version control, Weather, Zodiac
