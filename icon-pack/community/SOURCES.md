These 16 collections (4,673 icons) were pulled from the `dist/svg/` sprite
sources aggregated by [leungwensen/svg-icon](https://github.com/leungwensen/svg-icon),
tracing back to their original upstream projects. Each is independently and
permissively licensed (MIT / Apache-2.0 / CC0) with no attribution chain
or share-alike obligation, so each is safe to repackage and sell as-is.

## Deliberately excluded from this pack

Pulled from the same source repo but left out because they are brand logos,
trademarks, or carry attribution/share-alike terms that complicate resale:

- `logos` (svgporn.com brand logos), `simple` (Simple Icons — brand logos),
  `payment` / `payment-web` (card network marks: Visa, Mastercard, etc.),
  `windows` (Microsoft's icon set), `zocial` (social network brand icons),
  `dev` (devicons — logos of programming languages/tools) — **trademark risk**.
- `subway` (transit system line symbols) — excluded out of caution.
- `awesome` (Font Awesome Free), `weather` (Weather Icons), `typcn` (Typicons),
  `entypo` (Entypo), `game` (Game-icons.net), `icomoon` (IcoMoon Free) —
  excluded because they require attribution and/or share-alike terms
  (CC BY / CC BY-SA / SIL OFL) that need to be surfaced to your buyers if
  you want to add them later; verify and credit correctly before including.

Double-check current upstream licenses before publishing — projects
occasionally relicense.
